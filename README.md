# Pentamaster Website Recreation

An assignment project recreating the website of Pentamaster Corporation Berhad, a Malaysian automation solutions provider. This is a student project and is **not affiliated with, or endorsed by, Pentamaster**. Company information shown on the pages is used for learning purposes only.

Built with HTML, CSS and vanilla JavaScript. It is front-end only, with no backend or database.

## Pages and Features

### About (`pentamasterAbout.html`)
- Slide-out sidebar navigation
- Looping background video banner with the company mission and vision
- Company background section with images
- Bursa Malaysia stock information with a link to the live share price
- Core competencies grid
- Corporate structure chart showing the parent company and its subsidiaries with ownership percentages
- Awards and recognitions image slider with previous/next buttons
- Contact details and social media links

### Careers (`pentamasterCareer.html`)
- Benefits carousel with dot navigation
- Job listings, split into available and unavailable roles
- "Apply Now" modal with an application form and built-in validation (for example, Malaysian phone number format)
- The form is a front-end demo: on submit it shows a confirmation alert and resets. No data is sent or stored.

### Media News (`pentamasterNews.html`)
- Grid of news articles that link to the original sources
- Year filter built with JavaScript and `data-` attributes

## How to Run

1. Clone or download this repository.
2. Open `pentamasterAbout.html` in a web browser.

No installation or build step is needed.
